  <h1>Instagram Clone</h1>
  <p>A full-stack Instagram clone built with React and Firebase</p>
</header>

<div class="content">
  <h2>Features</h2>
  <ul>
    <li><strong>User Authentication:</strong> Users can sign in with Firebase Authentication.</li>
    <li><strong>Add Posts:</strong> Signed-in users can upload images and add captions.</li>
    <li><strong>Comments:</strong> Users can comment on posts.</li>
    <li><strong>Real-time Updates:</strong> New posts and comments are instantly updated in real-time using Firebase Firestore.</li>
  </ul>

  <h2>Technologies Used</h2>
  <ul>
    <li><strong>React:</strong> For building the user interface.</li>
    <li><strong>Firebase:</strong> For authentication, Firestore database, and storage of images.</li>
    <li><strong>Material UI:</strong> For UI components like buttons and avatars.</li>
  </ul>
