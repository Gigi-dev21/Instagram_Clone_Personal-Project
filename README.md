Instagram Clone
A full-stack Instagram clone built with React and Firebase. This app allows users to sign in, add posts, and comment on posts. New posts are displayed at the top of the feed.

Features
User Authentication: Users can sign in with Firebase Authentication.

Add Posts: Signed-in users can upload images and add captions.

Comments: Users can comment on posts.

Real-time Updates: New posts and comments are instantly updated in real-time using Firebase Firestore.

Technologies Used
React: For building the user interface.

Firebase: For authentication, Firestore database, and storage of images.

Material UI: For UI components like buttons and avatars.
